# Rawkaki — Artist Portfolio

A static, dependency-free portfolio site for an artist/creator.

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Customize

- **Text & sections:** edit `index.html` (Photography, Print On Demand, Projects sections).
- **Colours & fonts:** edit the CSS variables at the top of `css/styles.css`.

## Deploy

Any static host works: GitHub Pages (Settings → Pages → deploy from `main`), Netlify, or Vercel.
